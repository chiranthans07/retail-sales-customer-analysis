# Retail Sales & Customer Behavior Analysis

An end-to-end data analytics project exploring retail transaction data to uncover sales trends, product performance, customer purchasing behavior and customer segmentation.

## Live Dashboard
https://retail-sales-data-analysis-b4d5hp5nrnizovwewcpgw8.streamlit.app/

## Project Overview
This project analyzes historical retail transaction data to understand sales performance, customer behavior, purchasing trends and business opportunities. The workflow covers data cleaning, exploratory data analysis, SQL-based analytics, RFM customer segmentation and an interactive dashboard.

## Dataset
- Source: UCI Machine Learning Repository – Online Retail
- Dataset: Online Retail
- Original records: 541,909 transactions
- Period: December 2010 – December 2011
- Country: United Kingdom-based online retailer with international customers

## RFM Analysis
Customers are analyzed using:
- **Recency:** How recently a customer purchased
- **Frequency:** How frequently a customer purchased
- **Monetary:** How much a customer spent

These metrics help categorize customers based on purchasing behavior and identify potential loyal customers, high-value customers and customers requiring engagement.
